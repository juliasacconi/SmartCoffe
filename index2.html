Comandos Git

Git Init


    git init - Inicializa repositório e mantem um histórico

Git Status


    git status - Podemos visualizar o funcionamento correto do
    repositório

Git Add


    git add - Adiciona arquivos ao índice
    git add nome_pasta ou
    git add .

Git Commit


    git commit - Cria um novo commit com as alterações
    

    git commit - Irá enviar uma mensagem de confirmação para o GitHub
    git commit -m "Mensagem que desejo"

Git Log


    git log - Irá exibir o histórico de commits
